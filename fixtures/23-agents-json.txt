1. TRUST IS AN EXACT PATH ON 1.2.14
   A workspace agent (`.agents/agents/ctl.md`) was listed only when trustedWorkspaces held the
   workspace itself:
     ["/Users/<me>"] (this machine's real entry)   → not listed
     ["<parent>"], ["<parent>/"]                   → not listed for <parent>/child
     ["<parent>/child"]                            → listed
   Same with and without a real `git init`. The plugin used to treat an entry as covering every
   path beneath it (read off the 1.2.11 binary, never probed), which offered agents agy would not
   load. Launching from a subdirectory of a trusted workspace lists no workspace agents either,
   but that is the launch-directory rule from fixture 13 (no walk-up), not trust.
